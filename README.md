# Overview

This project is a console based task manager written in Kotlin. The program allows the user to add tasks, view all tasks, view completed tasks, view pending tasks, mark tasks as complete, edit existing tasks, and remove tasks. I created this software to practice the core syntax and structure of Kotlin in a practical way instead of only reading about the language.

My purpose for writing this software was to strengthen my understanding of Kotlin as an object oriented language and to get more comfortable using variables, conditionals, loops, functions, classes, collections, data classes, and the when keyword. I wanted to build a small but useful program that would help me move beyond basic syntax and understand how Kotlin code is organized in a real program.

# Development Environment

I developed this project using IntelliJ IDEA Community Edition, the Java Development Kit, and GitHub. IntelliJ was used to write, run, and test the Kotlin code, and GitHub was used to publish the finished project.

This software was written in Kotlin and runs on the JVM. I used the Kotlin standard library and built in language features such as mutable lists, data classes, loops, functions, conditionals, and the when expression.
